# Amazon Sub-Image Layout Patterns

## Product Hero

Use for first impression. Large product at center or dominant side, with 2-4 badges. Best for new formats, large capacity, set value, or distinctive package.

## Benefit Badges Around Product

Use when a product has several simple benefits. Keep badges short. Avoid cluttering with long explanations.

## 3-Step / How-To

Use for ease-of-use or process claims. Show `open -> use -> result` or equivalent. Works best with hand photos and arrows.

## Before / After

Use for handoff from pain to solution. Avoid unfair competitor attacks. Label sides as user situations rather than brand targets.

## Split Comparison

Use for choosing between formats, sizes, or use cases. Prefer neutral labels and factual rows.

## Close-Up / Material Detail

Use for texture, individual packaging, components, or craftsmanship. Make one detail very large.

## Usage Scene Full-Bleed

Use for lifestyle fit. Main photo should dominate. Copy should be minimal and anchored to the scene.

## Usage Scene 3-Up

Use for multiple occasions: home, work, travel, gift, storage, night, outdoor. Keep each scene visually distinct.

## Specification Card

Use for size, capacity, ingredients, set contents, compatibility, storage, or dates. Pair with a supporting visual so it does not become a table-only image.

## Storage / Size Scale

Use for EC purchase anxiety around bulk, storage, compactness, or portability. Include shelves, hands, bags, counters, or real-world scale.

## Q&A / Anxiety Resolution

Use when reviews show repeated pre-purchase concerns. Use 2-3 questions max.

## Review Voice / Evidence Snippet

Use only when source review wording is available and quoting is allowed/appropriate. Avoid medical or performance claims unless verified.

## Set Contents / What You Get

Use for bundles, multi-packs, accessories, replacements, or starter kits. Make quantity and contents visually countable.

## Lineup / Choice

Use for flavor, color, size, or variant selection. Avoid if it distracts from the target SKU.

## Problem Statement

Use when category pain is strong. Show the problem visually, then connect to product. Avoid fear-based or exaggerated scenarios.

## Trust / Reassurance

Use for official specs, manufacturing, origin, inspection, or brand history. Requires source-backed claims and careful wording.
