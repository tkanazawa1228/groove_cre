# Amazon Subimage Layout Pattern Library

Use this skill to choose visual structures, not claims. Pair it with product/review/market evidence from other skills.

## Pattern Selection Rules

- Use a different pattern for each image when possible.
- Do not choose a layout pattern before defining the image role.
- Match the pattern to the purchase job: recognize, understand, compare, imagine use, reduce anxiety, confirm specs.
- Avoid using `information card` as the default for every image.
- If two images need a similar structure, vary visual subject, crop, split, scale, and reading direction.

Read `references/patterns.md` for the pattern catalog.

## Six-Image Baseline Sequence

A balanced Amazon sub-image set often uses:

1. Product hero or strongest differentiator
2. Mechanism/steps/how-to
3. Close-up/detail or material proof
4. Before/after, comparison, or anxiety resolution
5. Specs/storage/size/set contents
6. Usage scene, lifestyle, or summary

Adjust this sequence based on category and evidence.

Then provide a short sequence rationale.
